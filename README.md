# Aprendiendo Git & GitHub

## paso 1
- Inicializar el nuevo repositorio
'''
git init
'''
-Directoriio de  trabajo donde se escribe el codigo
## paso 2
- Enviar los nuevos archivos o archivos modificados al area de preparacion
'''
git add index    archivos por archivo
git add .    todo en uno
''''
-El area de preparacion es donde se prepara los cambios realizados
